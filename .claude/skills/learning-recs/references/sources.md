# Credible sources by topic

A starting map, seeded from what already appears in the tech-contents notes plus well-established sources in the same areas. It is a place to begin looking, not a whitelist: good pieces from elsewhere are welcome if they pass the credibility test in SKILL.md, and a name here does not excuse a weak piece. Check each source's recent output with a search; do not assume a URL or that a source is still active. Add sources the user reacts well to.
